入力すると右側に求人票がそのまま表示されます。入力内容はこのブラウザに自動保存されます。

掲載設定
公開の流れ：「① GitHubに登録して公開する」を押す → GitHubの画面が開くので、下の緑色の 「Commit changes...」 → もう一度 「Commit changes」 を押す → 約1〜2分で求人サイトに反映されます。
既存の求人を修正するとき：「保存した求人を開く」または GitHub の jobs フォルダからファイルを開き、鉛筆マーク（編集）に「JSONをコピー」した内容を貼り付けて保存します。
募集を終了するとき：公開状態を「下書き」にするか、掲載期限を過去の日付にして保存します。
